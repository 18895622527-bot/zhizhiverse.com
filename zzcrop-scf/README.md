# zz-crop（腾讯云 SCF，广州）—— 老照片自动裁剪 / 摆正 / 去花边 / 构图 / 换背景

小程序 → uniCloud `zzCrop` → 这个 SCF → 回一张只剩照片本身的图 → 再交给阿里云 FC 的 CodeFormer 修脸。

部署：腾讯云「云函数」→ 函数 `zz-crop` → 函数代码 → 本地上传 zip（这四个 .py 打成 zip，文件放在 zip 根目录）→ 部署。
运行环境 Python 3.9，层 `zz-crop-opencv` + `zz-crop-mediapipe`（opencv-headless 4.10.0.84 / mediapipe 0.10.14 / numpy 1.26.4）。
环境变量 `ZZ_TOKEN`、`DASHSCOPE_KEY` 只在 SCF 控制台里配，不进仓库。
