# 照片预处理云函数 部署说明（腾讯云 SCF）

摆正 / 裁剪 / 去花边 / 人脸定位 / 重新构图 / 换背景。不要 GPU，一张约 0.0001 元。

**三个包**（我已经在 Python 3.9 x86_64 上验过，直接用，不要自己重打）：

| 文件 | 是什么 | 大小 |
|---|---|---|
| `zz-crop-layer1-opencv.zip` | 层 1：OpenCV | 47 MB |
| `zz-crop-layer2-mediapipe.zip` | 层 2：MediaPipe + numpy | 49 MB |
| `zz-crop-code.zip` | 代码：`index.py` + `crop.py` | 14 KB |

⚠️ 层里的 mediapipe 是 `--no-deps` 装的，并且用两个空壳顶替了 matplotlib 和 PIL。
不这么干依赖要 300 MB，超过 SCF 的上限，而且运行根本用不到。重打包的话这两点必须照做。

---

## 第一步：建两个层

腾讯云控制台 → 搜「云函数」→ 左边 **层** → **新建**

| 项 | 第一个 | 第二个 |
|---|---|---|
| 层名称 | `zz-crop-opencv` | `zz-crop-mediapipe` |
| 地域 | **上海**（跟下面的函数同一个） | 同左 |
| 上传方式 | 本地上传 zip 包 | 同左 |
| 文件 | `zz-crop-layer1-opencv.zip` | `zz-crop-layer2-mediapipe.zip` |
| 兼容运行环境 | **Python 3.9** | 同左 |

**验收**：层列表里两个都在，版本都是 1。

⚠️ 要是提示包太大不让本地传：先传到 COS（对象存储）的任意一个桶里，上传方式改选「通过 COS 上传」。

---

## 第二步：建函数

云函数 → **函数服务** → **新建** → **从头开始**

| 项 | 填什么 |
|---|---|
| 函数类型 | **事件函数** |
| 函数名称 | `zz-crop` |
| 地域 | **上海** |
| 运行环境 | **Python 3.9** |
| 提交方法 | 本地上传 zip 包 → `zz-crop-code.zip` |
| 执行方法 | `index.main_handler`（默认就是，别改） |

展开 **高级配置**：

| 项 | 填什么 | 为什么 |
|---|---|---|
| 内存 | **1024 MB** | OpenCV + MediaPipe 加载完约 300 MB，大图处理时再翻一倍 |
| 执行超时时间 | **30 秒** | 实测一张 0.3~1.2 秒；冷启动加载依赖要几秒 |
| 环境变量 | `ZZ_TOKEN` = 随便一串，比如 `openssl rand -hex 16` 生成 | 这个地址挂在公网，不设就是谁都能调 |
| 层 | 绑定 `zz-crop-opencv` 和 `zz-crop-mediapipe` | 两个都要 |

⚠️ **ZZ_TOKEN 不要截图发我。** 一会儿填进 uniCloud 的 `zzCrop/config.json` 就行。

触发器：**创建触发器 → API 网关触发器**，请求方法 `POST`，鉴权「免鉴权」（我们自己用 ZZ_TOKEN 把关）。
如果你的控制台里有「**函数 URL**」这一项，用它代替 API 网关 —— 更简单也不收网关的钱。

**验收**：函数详情页拿到一个 `https://…` 地址。

---

## 第三步：在控制台里试一次

函数详情 → **函数代码** → 右边 **测试** → 测试事件选「API Gateway 事件模板」，把 `body` 那一行换成：

```json
"body": "{\"image\": \"\"}"
```

点测试。**期望返回** `statusCode: 400`，body 里是 `没给图片`。
—— 这说明依赖都加载起来了（没起来会直接报 `ModuleNotFoundError`）。

⚠️ 第一次要等 5~10 秒（冷启动加载 250 MB 依赖），之后就快了。

---

## 第四步：接进 uniCloud

`zzCrop` 云函数（我另外给），`config.json` 填：

```json
{ "endpoint": "<第二步拿到的地址>", "token": "<ZZ_TOKEN 那串>" }
```

右键 → 上传部署 → 本地运行 `{"op":"ping"}`，期望 `{ code: 0 }`。

---

## 常见的坑

| 现象 | 原因 |
|---|---|
| `ModuleNotFoundError: cv2` | 层没绑上，或者层的兼容环境没勾 Python 3.9 |
| `No module named matplotlib` | 层 2 没绑上（空壳 matplotlib 在层 2 里） |
| 超时 | 内存给少了（128 MB 跑不起 MediaPipe），改 1024 |
| 403 | 两边 token 不一样 |
| `fix` 为空串 | **不是故障**。没认出照片的边，调用方让用户自己框 |
